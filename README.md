# Wakib Uddin — Python Backend & Data Portfolio

A responsive, animated personal portfolio highlighting my Python backend, data analysis and machine-learning projects.

## Highlights
- Modern dark interface with cyan, blue and violet accents
- Responsive navigation and project cards
- Animated role headline and subtle scroll reveals
- Reduced-motion accessibility support
- Direct links to GitHub projects and LinkedIn
- No frontend framework or build step required

## Built with
- HTML5
- CSS3 (Grid, Flexbox, custom properties and responsive media queries)
- Vanilla JavaScript
- Google Fonts (Manrope and DM Mono)

## Run locally
```bash
git clone https://github.com/Wakib-Uddin/Portfolio.git
cd Portfolio
```
Open `index.html` in a browser. Google Fonts are loaded from Google Fonts CDN; the rest of the site is static HTML, CSS and JavaScript.

## Deploy with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and `/(root)` folder, then save.
4. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.
