# Wakib Uddin — Data Analysis Portfolio

A clean, responsive portfolio focused on my learning journey in data analysis, Python, SQL, Excel and machine learning.

## Design
- Editorial, data-focused visual style
- Responsive layout for desktop and mobile
- Lightweight chart illustration and rotating role text
- Reduced-motion support
- Direct links to source repositories

## Built with
HTML5 · CSS3 · Vanilla JavaScript · Google Fonts

## Run locally
```bash
git clone https://github.com/Wakib-Uddin/Portfolio.git
cd Portfolio
```
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save. GitHub will display the published URL in Pages settings after deployment.
